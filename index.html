Open Languages Collective

An open language-research harness that any modern AI agent can follow to build one traceable list of the world's languages and dialects.

View on GitLab See release v0.1.2

About

The major language datasets each describe the world's languages in their own way. This harness merges them into one master list: one row per language and dialect, every row traced back to the exact source rows and versions it came from, and every merge and possible duplicate on record. It is a set of plain-text instructions, rules and scripts, so it runs in whichever AI agent you already use.

Every row traced back to its sources

Glottolog anchors the list, with Ethnologue and ROLV merged in. Each entry links to the source rows and source versions behind it, and possible duplicates are scored and listed for review, never merged on a guess.

The line between "language" and "dialect" in this list is the one drawn in the source data. We recognize the value of the term "language variety" or "speech variety," a broader category that makes no such distinction.

Four steps from sources to a release

/catalog

Describes every source file and its version.

/masterlist

Merges the sources into one row per language and dialect.

/visualize

Draws an interactive map and two explorers.

/release

Packages a numbered version with its method.

Reproducible by anyone

The same inputs give the same list, down to one fingerprint anyone can compare. Each release records the source versions and the tool version that made it.
