About

Anyone exploring the world's languages soon finds that the major datasets vary. Each was built for its own purpose, with its own names, codes and line between language and dialect. The same language can appear under several names, cross national borders, and be counted differently in every source.

This harness brings them together in a way anyone can trace. It merges the sources into one master list, links every row to the source rows and versions behind it, records every merge and possible duplicate for review, and flags where the sources differ. It then turns the list into an interactive map and charts, so you can see where languages are spoken and explore how they relate. Every figure can be followed back to where it came from.

Bring your own data. Bring your own rules.

The harness is open for anyone to use. Start from the sources you trust, add your own lists alongside them, set the rules that fit your context, add skills for the steps your work needs, and run it in whichever AI agent you already use.

Every row traced back to its sources

Glottolog anchors the list, with Ethnologue and ROLV merged in. Each entry links to the source rows and source versions behind it, and possible duplicates are scored and listed for review, never merged on a guess.

The line between "language" and "dialect" in this list is the one drawn in the source data. We recognize the value of the term "language variety" or "speech variety," a broader category that makes no such distinction.

The harness in four steps

/catalog

Describes every source file and its version.

/masterlist

Merges the sources into one row per language and dialect.

/visualize

Draws an interactive map and two explorers.

/release

Packages a numbered version with its method.

Reproducible by anyone

The same inputs give the same list, down to one fingerprint anyone can compare. Each release records the source versions and the harness version that made it.
